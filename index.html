액자(모니터)와 좌표 이동을 이용한 원근감 및 끊김 없는 배경 이동 시뮬레이터

SCRATCH_DISPLAY_STAGE (480x360 Ratio)
정지됨
중앙 영역: 실제 모니터(액자) 화면
5 px/프레임
빨간점: 배경 1 파란점: 배경 2

실시간 배경 중심 x 좌표 상태

배경 1 (빨간점) 액자 내
x: 0

시작 위치: 액자 가운데 (x: 0)

배경 2 (파란점) 액자 밖 (왼쪽)
x: -480

시작 위치: 액자 왼쪽 (x: -480)

스크래치 알고리즘 블록

오른쪽 이동 스크립트
[시작] 클릭했을 때
무한 반복하기
x 좌표를 5 만큼 바꾸기
만약 x 좌표 > 480 라면
x 좌표를 -480 으로 정하기

핵심 원리 요약

1. 배경 1은 액자 가운데(x: 0), 배경 2는 액자 왼쪽(x: -480)에서 동시에 오른쪽으로 이동합니다.
2. 액자 오른쪽 끝(x: 480)을 완전히 벗어나면, 순식간에 다시 액자 왼쪽(x: -480)으로 이동하여 뒤따라옵니다.
